## What the integration changed

- `11df60b`: the installer lane found that a station whose download failed is not offered the dashboard's
  install button, because the installers always write `MODEL_PATH`. A configured path equal to the place the
  default classifier installs to is now treated as the default classifier.
- `843e67e`: the pages lane moved the Settings tabs to the shared head and left an existing test reading the
  heading it removed. The test reads the new head and was seen red on a mutant.
- `d585346`: the documentation lane's probe of N25-11. With `--watch-dir` equal to the recordings directory
  every clip is deleted once older than `STREAM_RETENTION_SECS`, locked or not, and a locked clip is deleted on
  a full disk. The station now logs that as an error at start. Neither installer sets the directories equal.
- The fixture's listening ledger credited one of its three sources with no listening, which the new Migration
  rate read as a fall in the recent weeks: three residents were drawn as passage birds. The ledger now covers
  every source that has detections.
- `08a9a58`, `4f66f3b`, `a56a7d2`: sentences the lanes reported as untrue outside their own files.
- The sweep table: four rows for reads the batch moved, two deleted for a lookup that now propagates its error.

## The seam measurement (decision 3)

With the real V2.4 model, one magpie call placed at 300 positions across two segment joins: at the default
overlap of 0, analysing each file alone and analysing the stream as one give the same score at every position.
With overlap 1.5 and 2.0 a call near the threshold is lost at 18 and 15 of the 62 positions near a join when
each file is analysed alone, against 12 and 6. One clip; the mechanism and not a recall figure. The table is in
the decisions file.

## Behaviour a station owner will notice

- An install whose classifier cannot be downloaded finishes and exits **75**, not 1. A script that treated any
  non-zero status as "not installed" will read a finished install as a failure.
- Counts of listened days can move by a day or two: a day now counts when the station recorded at least half
  its typical day, on every page.
- The Migration page may draw different species: it ranks by rate per listened time.
- Chart colours: marks that are not a species are a neutral ink.
- The kiosk's mode and exit links are visible without a hover.
- The V2.4 model is fetched from this project's `models-v2.4` release first.
