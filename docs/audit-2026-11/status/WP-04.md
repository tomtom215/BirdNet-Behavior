## What was not verified

- Nothing ran on a real microphone, PipeWire server or camera. The `pan` filter's effect on real stereo audio
  is FOLKLORE (ffmpeg's documented `pan=mono|c0=cN`); the argv is what is tested.
- That every capture path writes 16-bit is read from the code (`arecord -f S16_LE`, ffmpeg `pcm_s16le` for RTSP,
  ffmpeg's WAV default for PipeWire), not measured from a recorded file.
- Migration 62 was run on a fresh database and by the existing migration tests, not on a copy of a field
  station's database.
