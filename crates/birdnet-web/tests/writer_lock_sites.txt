# Every `with_db(` in crates/birdnet-web/src that is allowed to hold the single writer connection.
#
# `with_db` takes the connection every writer shares, the capture daemon's detection inserts
# included. A read does not belong there: it waits behind a write, and the write waits behind it.
# Reads go through `with_read_db` (the pool of read-only connections), and through
# `heavy_read_permit` / `run_blocking_heavy` when they scan the whole history.
#
# A new `with_db` must be added here with the reason it writes. That is the point: the default for
# a database call in a handler is the pool, and a line in this file is the review of the exception.
# `the_writer_lock_is_for_writing.rs` fails on a site that is not listed and on a listing that no
# longer exists.
#
# file :: fn   count   reason
